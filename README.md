A bold, one-page tech portfolio. Color-blocked sections, browser-window project cards, sticker-style skill tags, and a striped scrolling ticker.

### See the one, the only, live demo... [here](https://the-esha-account.github.io/portfolio/)!

## 📁 Structure

```
├── index.html        ← all page content & sections
├── css/style.css      ← design tokens + all styling
├── js/script.js        ← mobile menu + footer year
└── assets/              ← put your photo/images here
```

## 📝 Notes

- Respects `prefers-reduced-motion` (ticker and cursor animations pause for users who request less motion)
- Keyboard-navigable with visible focus states
- Fully responsive, including a mobile nav menu
